A Roblox HvH (Hacker vs. Hacker) script, for games like **PenaBlox HvH**.

## Features

- **HvH:** Uhhh maybe no spread and stuff. Depends on the place.
- **Game Compatibility:** Primary support for **PenaBlox HvH**, with support for other HvH places.
- **Junky & Slow:** Very bad coder, everything could be faster.

## Launcher

Run the script directly using your executor(Madium,Real,Volt and etc...):

```lua
loadstring(game:HttpGet("https://github.com/123hoipopper13r6/NeverHit.lua/blob/main/Loader.lua"))()
```
